Feature OCTOBER 8, 2025

🎯 Adaptive Reranking (Bloom-aware)

Quizzes now adapt the order of upcoming questions to your mastery—without sending question content to any AI. We only pass anonymized metadata (IDs, Bloom levels, difficulty, tags), and the AI returns a JSON list of IDs to re-rank a small candidate set. Guardrails include strict JSON-only output, low temperature/tokens, timeouts, caching, cooldowns, per-day budget caps, and local fallbacks. Integrated in custom and roguelike quiz scenes.

Docs OCTOBER 8, 2025

📚 Bloom-aligned Authoring Guide

We published a concise guide for tagging questions with Bloom’s taxonomy so dashboards and mastery graphs stay accurate. Always set bloomTarget using one of: remembering, understanding, applying, analyzing, evaluating, creating. See docs/documentation/BloomQuestionAuthoring.md.
