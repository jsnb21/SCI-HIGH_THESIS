CustomQuizScene Usage\n=====================\n\nPurpose:\n  Allow professors to create and deliver custom quizzes dynamically without bundling a static JSON file.\n\nScene Key: CustomQuizScene\n\nStart Parameters (example):\n  this.scene.start('CustomQuizScene', {\n      professorId: 'prof123',\n      quizId: 'midterm1',        // optional, if omitted and only one quiz exists it loads that quiz\n      difficulty: 'medium',      // optional (affects scoring multipliers like other quiz scenes)\n      topic: 'Custom'            // optional label for point tracking\n  });\n\nData Source Hierarchy:\n  1. Firebase Realtime Database path: customQuizzes/{professorId}/{quizId}\n     Structure: { meta: { title, subject, createdAt, createdBy }, questions: [ { question, options[], correctIndex, type? } ] }\n  2. localStorage fallback key: sci_high_custom_quizzes (cached copy)\n\nAdding a Quiz Programmatically (Example):\n  const quizData = {\n     meta: { title: 'Midterm Review', subject: 'Algorithms', createdAt: new Date().toISOString(), createdBy: 'prof123' },\n     questions: [\n       { question: 'What is Big O of binary search?', options: ['O(n)', 'O(log n)', 'O(n^2)', 'O(1)'], correctIndex: 1 },\n       { question: 'Stable sorting algorithm?', options: ['QuickSort', 'MergeSort', 'HeapSort', 'SelectionSort'], correctIndex: 1 }\n     ]\n  };\n  // Save to firebase manually OR via a future professor UI form.\n\nClient Fallback Handling:\n  If quiz fails to load or has 0 questions, user sees an inline message and can press ESC to return to MainHub.\n\nExtending Question Types:\n  Add new fields (e.g., type: 'true-false', correctAnswer) and update normalization in customQuizService.normalizeQuestions.\n\nMaintenance Notes:\n  - customQuizService caches quizzes locally for offline development.\n  - Ensure Firebase is initialized before running scene for live data.\n  - To clear cache: localStorage.removeItem('sci_high_custom_quizzes');\n\nEnd.\n
